REMOTE SETUP

  2. 在远程桌面中的瑞丰目标机上，以管理员身份打开 CMD。
  3. 点击下方“复制命令”，粘贴到目标机 CMD 后按 Enter。
  4. 看到 SocksOverRDP remote bootstrap is installed and running. 后返回本页面，系统会自动继续。
